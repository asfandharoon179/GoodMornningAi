# Public assets

This folder is served as the app's static web root. The root [README](../README.md) contains setup, deployment, and configuration instructions.

`index.html` is the single-page client. `sw.js` handles the app shell and push notifications, `manifest.json` configures the PWA, and `icon.png` / `icon-512.png` are its install icons. Legal pages are available as static HTML files.
